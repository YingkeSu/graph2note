# Graph2Note

**把手写笔记和 PDF，整理成方便阅读、查找和继续修改的资料。**

课堂上记下的一页推导，开会时画出的流程图，下载后一直没读完的论文——Graph2Note 把这些零散内容放进一个本地文档库。你可以对照原稿校对，给资料分类，也可以围绕 PDF 提问，再把整理好的笔记带到 Obsidian 中使用。

[下载 macOS 版](https://github.com/YingkeSu/graph2note/releases/latest) · [反馈问题](https://github.com/YingkeSu/graph2note/issues)

---

## 从你手边的资料开始

| 你手上有…… | 可以用 Graph2Note 做什么 |
| --- | --- |
| 课堂笔记、手写作业、草稿照片 | 识别为可编辑的文字，对照原图补充和纠错，复习时按关键词查找。 |
| 会议记录、白板照片、流程草图 | 整理文字与图形内容，按项目归类，方便之后接着修改。 |
| 论文、讲义或其他 PDF | 逐页解析、搜索内容，围绕材料提问，并通过答案中的页码引用回看原文。 |
| 越积越多的学习和工作资料 | 用集合、标签和时间轴整理，在知识图谱中查看文档之间的关联。 |

如果你已经在用 Obsidian，可以把文档库导出为笔记、原稿和附件；如果还没用过，也可以直接在 Graph2Note 里阅读和整理。

## 安装与第一次使用

目前提供 **Apple Silicon Mac（M 系列芯片）** 的安装包。

1. 在 [下载页面](https://github.com/YingkeSu/graph2note/releases/latest) 下载 `.dmg`，打开后将 Graph2Note 拖入「应用程序」。
2. 打开应用，在侧栏「管理 → 模型设置」中填写你的 **API Key**，选择相应的供应商和模型，然后保存。
3. 点击「新解析」，先试一张清晰的笔记照片，或一份较短的 PDF。
4. 解析完成后对照原稿检查内容，再编辑、归类或导出。

API Key 是模型服务提供的访问凭据，需要在相应服务商处申请。应用支持 Kimi、DeepSeek 等内置供应商，也支持添加兼容接口的自定义服务。使用 AI 功能可能产生费用，具体以所选服务商的计费为准。

图片支持 JPG、JPEG、PNG，单张不超过 10 MB；PDF 不超过 50 MB。

> 当前安装包尚未经过 Apple 公证。首次打开若被 macOS 拦截，请按系统提示在「系统设置 → 隐私与安全性」中允许打开。

## 整理之后，还能做什么

- **继续编辑**：识别结果可以修改并保存，原稿留着供你核对。
- **找到旧资料**：搜索文档和已解析的 PDF 内容，不必只靠记住文件名。
- **回顾这段时间**：按时间浏览资料，也可以生成带来源信息的科研周报草稿。
- **导出自己的笔记**：导出到 Obsidian，或继续使用 Markdown 文件。导出是单向的，在 Obsidian 中做的修改不会自动同步回来。

## 关于数据和识别结果

文档库和模型设置保存在你的电脑上。API Key 在应用内输入、本地保存，保存后不会在界面中回显；安装包不附带密钥。

**使用 AI 解析、问答等功能时，相关图片或文本会发送给你配置的模型服务。** 涉及个人信息、公司内部资料或尚未公开的研究内容时，请先确认这些材料适合交给该服务处理。

手写字、公式和复杂图表可能识别有误，问答也可能遗漏细节。重要内容请对照原稿确认；周报等生成内容适合作为你继续修改的草稿。
