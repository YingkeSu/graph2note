# U4：知识图谱交互升级

Status: merged
Labels: track-ux

## What to build

覆盖 usable-product-iteration 草案 §1 P1-6。当前图谱（43 文档全量渲染、节点重叠、无缩放平移、边来源不可辨）升级为可用的导航视图。

- **布局与可读性**：分层/力导向布局消除节点重叠（SVG 内实现或轻量算法自写，不引外部图库；若引入 CDN 库需在 issue 评论记录选型理由且保持 zero-build）；节点带文档/主题/标签类型区分，边按 topic/tag/manual 三来源区分（现有图例保留）。
- **缩放与平移**：滚轮缩放、拖拽平移、适应视图/重置按钮。
- **过滤**：按集合/标签/边来源过滤显示子图；文档数多时默认视图做聚类收敛（如主题层聚合，点击展开文档层）。
- **聚焦邻域**：点击文档节点高亮其邻域并淡化其余；再点击空白恢复。
- **导航语义不变**：点文档 → 三栏编辑器；点主题 → 文档列表过滤；点标签 → 标签过滤（现有行为，验收不回退）。

数据源沿用 `/api/graph`（可扩展响应字段，如聚类层级信息，但不改变现有语义）。

## Acceptance criteria

- [ ] fixture 图（≥30 文档 + 多主题/标签）渲染后无节点重叠（节点包围盒相交数为 0，程序化断言），默认视图无需缩放即可辨认主体结构。
- [ ] 缩放/平移/适应视图可用，缩放范围覆盖 0.25×–4×；操作不丢失节点。
- [ ] 按边来源与集合/标签过滤后仅显示匹配子图；过滤状态有 UI 可见反馈。
- [ ] 点击文档节点进入邻域聚焦态，导航三类节点行为与现状一致（DOM 断言）。
- [ ] 真实库（43 篇）截图前后对比留证（`visual-qa capture`），对比图显示重叠显著改善。
- [ ] 图谱视图模型与 API 测试全绿；不新增真实模型调用。
