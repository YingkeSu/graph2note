# U3：编辑器工作区改造（信息侧板 + 原图查看器 + 快捷键）

Status: merged
Labels: track-ux

## What to build

覆盖 usable-product-iteration 草案 §1 P1-5。编辑器从「三栏 + 下方纵向堆 5 个区块」改为「三栏为主 + 右侧信息侧板」，并解决手稿原图看不清的问题。

- **信息侧板**：标签、集合、时间元数据（含手工修正）、待整理标记、版本信息收进右侧可折叠侧板（或三栏上方工具条 + 抽屉，实现自定但必须脱离纵向主轴）；默认收起或紧凑态，编辑 Markdown 时零干扰。表单行为（添加/移除标签、加入/移出集合、日期修正、待整理勾选）与现有 API 完全一致，只是布局迁移。
- **原图查看器**：原图栏点击（或专用按钮）进入大图模式——放大/缩小（滚轮或按钮）、平移（拖拽）、适应窗口；手稿细节可读。退出返回编辑器。PDF 来源页同理复用（`/api/pdf/{id}/page/{n}`）。
- **快捷键**：⌘S 显式保存（与自动保存并存，给出已保存反馈）、⌘/ 收起展开信息侧板、Esc 退出大图模式；输入框聚焦时不劫持。
- **状态可见性**：自动保存指示、解析警告（warnings）在工具条常驻可见，不被滚动带走。

不改：解析流程、版本机制、Markdown 双向同步逻辑、导出/删除操作语义（操作按钮位置可随布局迁移）。

## Acceptance criteria

- [ ] 编辑器主轴只有三栏 + 工具条：标签/集合/时间元数据/待整理在侧板或抽屉内完成全部操作，1440×1000 下三栏可视高度较改造前增加（截图前后对比留证）。
- [ ] 大图模式支持缩放（≥2× 放大后手稿笔画清晰可辨）、平移、适应窗口、Esc 退出；图片上传与 PDF 页两种来源都可用。
- [ ] ⌘S 保存、⌘/ 侧板、Esc 退出在 macOS Chrome 行为正确，且在 textarea/input 聚焦时不误触发（⌘S 除外——它应当工作）。
- [ ] 元数据/标签/集合全部操作有 DOM 断言测试（侧板内表单 → API 调用 → 状态更新），行为与迁移前等价。
- [ ] 自动保存指示与 warnings 在工具条常驻，滚动编辑器不丢失可见性。
- [ ] 既有 document/metadata/tags/collections 相关离线测试全绿。
