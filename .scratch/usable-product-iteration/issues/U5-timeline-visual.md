# U5：时间轴可视化升级

Status: merged
Labels: track-ux

## What to build

覆盖 usable-product-iteration 草案 §1 P1-7。时间轴从「分组卡片列表」升级为有时间感的可视化视图，保持只读定位（不触发解析、不编辑内容）。

- **可视化形态**：垂直时间轴主干 + 按天/周分组的刻度与条目（现分组 API 语义保留）；条目带缩略图、标题、来源图标、标签计数；空档期显示间隔指示（如"间隔 12 天"），体现节奏感。
- **主题聚合**：同主题相邻条目的聚合展示从纯文本改为视觉聚合（连续色带/分组框），展开/收起交互保留。
- **密度总览**（可选加分项）：顶部迷你密度条（按月文档量），点击跳转到对应分组。
- **导航**：点击条目进三栏编辑器（现有行为）；无日期文档区保留在尾部，文案说明回退原因。
- **性能**：43+ 文档无感知卡顿；缩略图懒加载。

数据源沿用 `/api/timeline`（可扩展字段，不改现有语义）。

## Acceptance criteria

- [ ] 时间轴呈现主干+刻度形态（截图留证，与改造前对比），条目含缩略图/标题/来源图标/标签计数。
- [ ] 日/周分组切换语义与现状一致（分组排序稳定性测试不回归）；空档期有间隔指示。
- [ ] 同主题相邻聚合视觉可辨，可展开/收起；聚合语义沿用现有 API 字段。
- [ ] 点击条目进入对应文档编辑器；时间轴内无任何写操作（DOM 断言 + API mock 验证零非 GET 调用）。
- [ ] 无日期与空库两种状态有明确展示（现有空状态文案可沿用）。
- [ ] 43 篇真实库截图验证可读性；缩略图懒加载断言（视口外不发请求）。
