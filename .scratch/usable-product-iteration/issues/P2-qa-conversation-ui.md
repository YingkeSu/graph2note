# P2：问答对话式界面与一级入口

Status: ready-for-agent
Labels: track-pdf-qa

## What to build

覆盖 usable-product-iteration 草案 §1 P0-3 与 §2.4 的 UI 部分。把 PDF 问答从 Library 页里的小输入框升级为一级视图的对话界面（消费 P1 的会话 API）。

- **一级入口**：侧栏新增「问答」视图（U1 骨架下）；进入后是 scope 选择（默认全部已导入 PDF）+ 对话区。
- **对话 UI**：消息气泡（用户右 / 助手左），助手消息内嵌**引用芯片**（`[PDF 名 · p12]` 样式），点击跳原页（复用现有 source-page 跳转路径）；加载中显示该轮的等待态而非全屏阻断；出错可重试当轮。
- **会话管理**：当前会话持久（刷新/重启回来还在，消费 P1 落盘）；「新会话」按钮显式开新话题；历史会话列表（可选加分项，不做不阻塞验收）。
- **搜索与问答的关系**：现有 PDF 关键词搜索入口在本视图中保留为辅助工具条（或在顶栏搜索框联动，视 P3 进度协同——两者不得同时大改 `pdfsearch` 前端，派发时由调度协调先后）。

## Acceptance criteria

- [ ] 问答为侧栏一级视图，含 scope 选择、对话区、新会话按钮；Library 页不再承载问答表单（截图前后对比留证）。
- [ ] 助手消息的引用芯片点击跳转到对应 PDF 原页（DOM 断言 + API mock）。
- [ ] 刷新页面后会话恢复（消费 P1 落盘）；新会话按钮开启空会话，旧会话不被删除。
- [ ] 3 轮对话的请求组装与 P1 契约一致（session_id 持续传递）；每轮引用独立（沿用 P1 fixture 断言前端展示）。
- [ ] 等待/错误/空状态有明确 UI；错误重试只重发当轮。
- [ ] 离线 DOM 断言测试覆盖主路径；无真实 LLM 调用进 CI。
