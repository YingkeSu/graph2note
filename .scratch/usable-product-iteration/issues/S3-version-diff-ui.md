# S3：版本对比视图（编辑器内）

Status: merged
Labels: track-semantic

## What to build

覆盖 usable-product-iteration 草案 §2.3 的 UI 部分。在编辑器（U3 改造后的工作区）中提供版本切换与对比体验，让"这版改了什么"一眼可见。

- **版本切换器**：编辑器信息侧板（或工具条）中的版本列表（消费 S2 的版本链 API）：时间、来源、diff 摘要徽标（如 "+3 −1 ~2"）；点击切换查看该版本内容（只读查看历史版本，编辑始终作用于最新版——防止旧版静默回滚）。
- **对比视图**：任选两版（默认 最新 vs 前一版）：
  - Markdown 渲染级并排/行内高亮（新增绿/删除红/修改黄，块级粒度来自 S1 的块定位，不重新发明文本 diff——块内文本高亮允许用现有 CDN/简单算法，但块归属以 S1 为准）。
  - 原图对照：两版 `preprocessed.png` 并排（图片查看器复用 U3 大图模式）。
  - 摘要条：按块类型的变更统计 + 模板化自然语言摘要（"修改 2 个段落、移动 1 个公式…"，模板拼接，零模型调用）。
- **从 diff 定位**：点击对比中的变更块，编辑器滚动到当前版本对应块（块定位来自 S1）。

## Acceptance criteria

- [ ] 版本切换器展示版本链（时间/来源/diff 徽标）；查看历史版本为只读态且有明显"历史版本"标识，编辑动作被禁用或明确引导回最新版。
- [ ] 对比视图两版选择器、并排渲染高亮（块级粒度）、原图并排、摘要条齐备；1440×1000 截图留证。
- [ ] 摘要为模板拼接（无模型调用），统计数字与 S1 DiffReport 一致（同 fixture 断言）。
- [ ] 点击变更块能定位到最新版本编辑器中的对应块（DOM 断言）。
- [ ] 单版本/空 diff（两版相同）有明确安全态。
- [ ] 离线 DOM 断言测试覆盖切换、对比、定位主路径；既有编辑器测试（U3 交付后）不回归。
