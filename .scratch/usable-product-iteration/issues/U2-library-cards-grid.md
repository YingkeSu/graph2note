# U2：文档卡片富化与 Library 网格重排

Status: ready-for-agent
Labels: track-ux

## What to build

覆盖 usable-product-iteration 草案 §1 P1-4。解决「43 篇文档视觉上不可辨识」：卡片从"文件名 + 5 行空预览"升级为可辨识的知识卡片，网格密度提升。

卡片信息（数据全部来自现有 API，不新增后端字段时优先复用 `/api/documents` 现有返回；需要补充的轻量字段——如标题首行、缩略图 URL——允许在 API 响应中追加，不改变既有字段语义）：

- **缩略图**：`preprocessed.png` 的缩略（后端提供缩放端点或复用现有原图端点 + CSS 限制；注意 43 张原图直排的加载性能，需懒加载）。
- **标题**：Markdown 首个非空标题/首行，文件名降级为次要信息。
- **日期**：有效时间（元数据四时间戳的优先级链已有纯函数），显示到天。
- **标签 chips**（有则显示，≤3 个 + 溢出计数）与来源图标（图片上传 / PDF 页）。
- 卡片操作：点击进编辑器（现有行为）；悬停或角标暴露快捷操作（重新解析 / 删除，删除需确认——沿用现有确认交互）。

网格重排：默认紧凑网格（同屏 ≥12 张卡片 @1440px），提供密度切换（舒适/紧凑）可选；空状态与加载骨架（替换现有全屏 spinner 的 Library 场景部分即可，不要求全局改造）。

## Acceptance criteria

- [ ] 1440×1000 下 Library 同屏可见 ≥12 张卡片，每张含缩略图、可读标题（非文件名优先）、日期、标签 chips、来源图标；截图留证。
- [ ] 43 篇文档下首屏图片懒加载：初始网络请求只覆盖视口内卡片（测试断言初始 img 请求数）。
- [ ] 卡片标题取自 Markdown 首个非空标题/首行，无标题时降级文件名；日期取有效时间优先级链（复用既有纯函数，不重复实现）。
- [ ] 密度切换（如实现）或默认网格在窗口 1280–1920 宽度下无溢出、无横向滚动。
- [ ] 卡片点击/快捷操作行为有 DOM 断言测试；删除确认交互不回退。
- [ ] 既有 documents/collections 元数据测试全绿；新增 API 字段向后兼容（老字段不变）。
