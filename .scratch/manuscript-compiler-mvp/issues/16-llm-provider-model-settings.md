# LLM 供应商与用途模型设置

Status: merged

## What to build

覆盖 Manuscript Compiler v0.3 User Story 36。基于已有的 gateway registry，提供本地可持久化的供应商和用途级模型设置：解析视觉、IR 文本、图形提取和分类归纳分别可以选择生效的通道与模型。Web 设置界面和对应 API 展示当前配置、可用供应商、用途模型和可用性状态；用户切换配置后，后续解析、图形提取或分类任务无需改代码、无需重启即可使用新配置。

保留现有调用方模型标识与供应商映射契约，首版只支持手动选择和健康探针，不实现自动故障转移、供应商并跑或账号池管理；任何凭证只能由本地运行时读取，不能出现在 API 或界面响应中。

## Acceptance criteria

- [x] 设置 API/UI 能列出已注册供应商及其用途能力、当前生效供应商和模型；未知供应商、用途或模型会被拒绝并保留上一份有效配置。
- [x] 用户可以分别修改解析视觉、IR 文本、图形提取和分类归纳的供应商/模型，配置持久化后对下一次任务生效，无需重启进程。
- [x] 每个通道都有可注入的健康探针结果，UI 能区分可用、未配置凭证、认证失败和请求失败；CI 测试不进行真实网络调用。
- [x] 解析、IR、图形提取和分类归纳都会读取所选配置并沿用现有网关模型映射，任务结果能记录实际生效的供应商/模型。
- [x] 切换配置不改变 Document IR、分类方案和现有 Router 契约；不自动切换到其他供应商，也不启动多供应商并行调用。
- [x] 配置校验、健康状态、运行时生效和凭证不泄露均有离线单元/API/集成测试覆盖。
