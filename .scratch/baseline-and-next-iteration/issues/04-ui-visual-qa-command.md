# 建立 UI 截图视觉验收命令

Status: ready-for-agent

来源：[已确认拆分草案](../ISSUE-DRAFT.md)；[现状与需求检查](../ASSESSMENT.md)。

覆盖需求：用直接视觉 API 辅助验证开发后的网页/应用界面。

## What to build

提供开发者使用的命令，将自动化截图或本地应用截图与场景预期发送给视觉 LLM，生成可定位、可复核的结构化检查报告。复用现有供应商调用能力，首个已验证通道是 Kimi；不新增产品 UI 或面向用户的模型调用流程。

## Acceptance criteria

- [ ] 从一个真实页面场景到截图、API 检查、报告产出有完整可重复命令；支持已有本地截图输入。
- [ ] 报告记录场景、视口、模型/提示词版本、输入指纹、问题严重度、视觉证据、区域定位及不确定性；不以截图推断未经操作的交互结果。
- [ ] 调用次数、单次及总时长、token 上限有明确边界；超时、认证失败、非法输出显示检查未完成，不能显示通过。
- [ ] 保存 usage、耗时与可重放结果；离线测试不读取真实凭证、不发网络请求，真实调用必须通过显式运行方式触发。
- [ ] 正常页面和预埋裁切/重叠问题样例均验证；记录模型判断与人工/确定性证据的对应，不把单次 LLM 通过作为唯一发布门槛。
