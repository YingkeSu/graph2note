# 标签词表治理与文档标签

Status: merged

## What to build

覆盖 Knowledge Workspace User Stories 6–9。为工作台增加持久化标签词表和文档标签关系：新增标签先经过空白、大小写和分隔符规范化，自动打标签时把现有词表和别名作为可复用范围，能复用时不创建同义标签；用户也可以在文档详情中手工添加或移除标签。词表页展示规范化标签、别名和使用次数，并支持合并与重命名，批量更新所有文档的归属。

端到端路径应包括标签词表、自动分类输出校验、文档级读写 API、词表管理 UI、导出消费以及存量文档的增量治理；主题分类仍与细粒度标签分层共存。

## Acceptance criteria

- [ ] 标签规范化是确定性的；等价的空白、大小写和分隔符输入归并到同一个规范化标签。
- [ ] 自动打标签优先复用已有规范化标签；新增标签只在词表中没有可复用项时创建，并保存别名关系。
- [ ] 文档标签的手工添加、移除和重载持久化可用；标签列表能返回每个标签的使用次数。
- [ ] 合并或重命名词表标签会批量更新相关文档、别名和统计，旧标签不再产生悬空归属。
- [ ] 标签词表、文档标签 API 与 Web 操作有契约测试；自动打标签使用录制 golden 输出，CI 不调用真实模型。
