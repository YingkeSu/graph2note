# 科研周报模板 v1（设计稿）

## 内容骨架

```text
科研周报
2026-09-07 — 2026-09-13
汇报人：<用户填写>                       2026-09-13
─────────────────────────────────────────────────
左栏（约 30%）          │ 右栏（约 70%）
【下周待办】            │ 1、本周概览（路线图）
□ <用户计划>           │ 主线 / 副线 / 本周产出 / 下一步
                       │ 2、本周进展
【关联批注】            │ （一）<主题或项目>
<贴着对应段落>          │ 本周做了什么 → 证据/结果 → 判断 → 下一步
                       │ 图 1 <图题与来源>；正文交叉引用
【tips / 碎碎念】       │ 3、<可选专题，如方法备忘>
<用户原话可锁定>        │ 按需使用表格、公式、代码与脚注
                       │ 4、问题与求助（允许仅标题）
                       │ 附录：原始笔记（参考材料）
                       │ 原图 / 页码 / 原文链接 / 文档版本
```

编号随可选章节连续计算，不能把“Coding 成本控制”写死为每周必填。

## 内容规则

- 默认科研版：概览、进展、问题与求助、按材料出现的附录；实验结果/过程记录/专题均为可选模块，可开关与排序。旧四节小结继续可读可导出。
- 概览聚焦研究主线、副线和成果，不用文档数替代成果。库统计、待整理数量置于辅助信息。
- 每条事实链接到材料及版本；用户口述记为“用户补充”；推论、猜想、待验证与已完成分开，缺证据不生成“完成实验”等结论。
- 空白与未完成有区别：无材料不调用模型、不编造；问题与求助可仅标题；计划默认未完成。重复材料合并叙述但保留全部来源。
- 追加默认保留已确认内容，替换需显式操作；支持段落原文锁定。重新生成创建新修订，旧修订可重新打开。
- 数据表保留单位、期间、口径和来源，不自动加入实时价格；模型成本讨论如有材料则区分输入、输出、缓存。
- 本次只复用已存在的原图/解析图，不引入新的图形生成器；整理图和原稿用同一来源身份关联。

## 版式与交互

- 独立宽幅周报阅读/编辑区，仪表盘保留入口及最近周报；章节导航、来源跳转、历史和导出沿用现有语义。
- A4 参考：约 21 mm 页边距；深蓝黑标题、宋体风格正文、紫灰手写批注；1.5 倍行距、细竖分隔线。字体缺失有可靠中文回退；字体随产物交付须保留许可。
- 桌面双栏，窄屏单栏：关联批注紧随被注释段落；下周待办靠近概览。批注绑定稳定段落 ID，绝不靠空行、固定高度或 DOM 序号对齐。
- 正文连续排版，侧栏独立安排；长批注可分段续注，标明关联段落/续注，不能为了对齐留空半页。正文锚点删除后提示重新关联。
- 图表按可用栏宽缩放且保持比例，长表重复表头，长 URL/代码可断行；标题不孤悬，图题不脱离图。附录原图可放大查看。
- PDF 用同一报告快照与 HTML/CSS 打印布局生成，具体引擎实现时根据仓库打包能力验证；不要求用户安装完整 TeX。导出需等待字体/图片完成。
- Markdown 导出顺序明确：概览侧注随概览，其余批注紧跟锚定段落，附录最后。带资产的报告导出包含 Markdown 与相对路径资产的包；纯文本仍支持单文件 Markdown。
- PDF 不含编辑按钮/生成状态，保留周区间、汇报人、日期、页码、图题与可点击来源；应用内链接与外部可用链接分别标示。

## 验收样本

短报告、9 页级长报告、很长侧注、连续侧注、跨页图表、中文/英文/①/emoji/公式/代码、损坏资产、空周报、旧版周报；390/768/1440 宽度与实际 macOS 应用。验收关注完整内容、来源、顺序、相邻关系、无遮挡和无批注造成的大块正文空白，不要求逐像素复制 LaTeX。
